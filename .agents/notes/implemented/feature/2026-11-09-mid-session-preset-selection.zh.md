# Agent Note: 会话中途切换预设

Status: implemented

[English](2026-11-09-mid-session-preset-selection.md) | 中文

## Problem

首回合后的锁定阻止了在同一任务中改变 Agent 行为。通过 fork 绕过锁定会改变会话标识，并移除指令历史。

## Decision

预设注册表通过 Agent 现有的维护机制，在回合之间选择新组合。获取组合期间到达的输入等待维护完成。切换保留 Session、完整的既有事件前缀和压缩历史，通过现有 `agent-preset/selected` 事件记录新预设。下次请求组装所选组合的提示词和工具。活动回合仍排除切换；无效定义和绑定前取消会保留原组合。

TUI `/preset` 和模型绑定的预设切换直接使用该操作。Web 在会话标题中复用选择器，工作期间禁用。显式选择可以改变已开始的 Session；自动暂存选择和新任务默认值同步仍仅针对空白 Session。

## Alternatives considered

**保留首回合锁定。** 即使没有活动请求或工具，它仍阻止所需的行为改变。

**Fork 并重置指令。** 它保留对话内容，却替换会话标识并移除既有模型可见上下文，不符合连续性的要求。

## Consequences

切换预设可能使下次请求的缓存前缀失效。既有回答、注入上下文和摘要仍属于历史，可能继续影响行为。在历史中保留系统更新的模型协议会同时保留旧系统消息和新消息。此操作不改写历史，也不保证模型遵从。

真实 loop 的 Loader 测试覆盖两种系统更新协议、历史不变、新提示词和工具、无效定义、延迟输入及绑定前取消。TUI 和 Web 测试覆盖各自的现有会话切换路径。
